# BrickOS v3.1 — generated rusEFI INI compatibility

- Accepts arbitrary filenames ending `.ini`, including `rusefi_proteus_f7.ini`.
- Recognizes `[TunerStudio] signature`, generated by rusEFI, preferring it over legacy `[MegaTune] signature`.
- Increases browser, upload, SD scanning, and SPIFFS validation size limits to 1,200,000 bytes (uploaded example is 943,745 bytes).
- Includes an end-to-end JavaScript parser test with the user-supplied generated Proteus F7 INI. The real firmware signature still must match exactly for tuning.
- Preserves AP-only Wi-Fi and existing USB CDC auto-connection.

**Important:** ESP32 SPIFFS availability and simultaneous use of other files can affect whether 1.2 MB actually fits; no live hardware validation was performed. `tests/fixtures/` contains the full user-provided INI only to support reproducible tests; this fixture is not flashed to the ESP32.
